# ECE Fundamentals Embedded Sketch

This folder contains an embedded/robotics sketch for a Boe-Bot style project.

## Files

| File | Purpose |
| --- | --- |
| `IDCBoeBot.ino` | Arduino sketch for the robot/controller behavior. |

## Opening and running

1. Open `IDCBoeBot.ino` in the Arduino IDE or an Arduino-compatible editor.
2. Select the correct board and port for the hardware.
3. Install any required board packages or libraries from the assignment/hardware setup.
4. Compile and upload to the device.

## Maintenance notes

- Keep the `.ino` source file in git.
- Do not commit generated build folders or `.DS_Store`.
- Add a wiring diagram or pin map here if this project is revisited; embedded projects are much easier to reproduce when hardware assumptions are documented.
