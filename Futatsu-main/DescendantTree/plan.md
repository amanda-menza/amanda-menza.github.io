## Abstract class `Person`

##### Parameters
- `name` (str): The name of the person.
- `children` (List[Person]): The list of descendants of the person.

##### Methods
- `pathToString() -> str`: Returns the role of the person.
- `findPathToDescendant(descendant: str) -> str`: Returns the path from the person to the descendant.
